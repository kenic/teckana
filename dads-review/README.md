# DADS 178件レビュー

`dist/index.html` はローカルでも開ける静的Webアプリです。判定（未確認・採用・不採用・保留）、コメント、修正読み・表記をブラウザのlocalStorageに保存します。候補の削除機能はありません。

同じURL・同じブラウザで続きを行えます。端末間同期はありません。バックアップJSONで別端末へ移動でき、読込時は既存記録を置き換える前に確認します。CSVは全178件または採用分だけを書き出せます。元の表記・読みを保持し、修正は別列です。

公開版とローカル版は別の保存場所になります。移動にはバックアップを使ってください。保存失敗時は画面右上に表示し、バックアップを促します。

入力: ../dads-poc/outputs/macos_user_dictionary_review.csv（178件）とmaster.csvの説明情報。元データを変更しません。
